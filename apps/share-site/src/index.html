Chrome setup

Load it unpacked

  1. Download the zip. Unzip it so you have an ImmersionKit extension folder.
  2. Open Chrome extensions. Go to chrome://extensions.
  3. Enable Developer mode. Use the toggle in the top-right corner.
  4. Choose Load unpacked. Select the unzipped ImmersionKit folder.
