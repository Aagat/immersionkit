# ImmersionKit Docs

This folder contains public-safe documentation for the open-source branch. It
focuses on how the extension works, how to run it locally, how assets are
shaped, and how to validate changes.

## Start Here

- [Getting started](./development/getting-started.md): install, local dev,
  builds, and optional local services.
- [Architecture](./engineering/architecture.md): runtime boundaries, asset
  loading, storage, and privacy constraints.
- [Extension assets](../apps/extension/src/assets/README.md): example asset
  schemas and runtime loading behavior.
- [Validation](./validation/README.md): test, smoke, and benchmark commands.
- [Agent workflow](./development/agent-workflow.md): public documentation and
  collaboration rules.

## Public Scope

Included:

- Extension runtime and UI.
- Shared runtime packages.
- Optional API/share-site examples.
- Public example assets and fixtures.
- Tests, smoke checks, and benchmark harnesses.

Excluded:

- Private curriculum/content packs.
- Private import and curation workflows.
- Private commercial plans, roadmaps, status ledgers, and deployment details.
- Large first-party TTS voice model files.

## Documentation Policy

Keep docs factual and implementation-oriented. Avoid publishing private business
plans, unpublished milestones, private infrastructure names, or content workflows
that are not part of this public branch.
